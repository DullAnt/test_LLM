# Приложение № 1 к приказу ПАО «Промсвязьбанк»

**От 31 мая 2023 № 97/3**

**Тарифы вводятся в действие с 23 июня 2023 г.**

---

## Тарифы за выдачу и внесение наличных денежных средств по картам физических лиц, эмитированным ПАО «Промсвязьбанк», в банкоматах банков-партнеров ПАО «Промсвязьбанк»[^1]

| № | Наименование | Стоимость услуги |
|---|--------------|------------------|
| **1** | **Выдача наличных денежных средств через банкоматы Банков-партнеров[^2]** | По тарифу за выдачу наличных денежных средств в банкоматах ПАО «Промсвязьбанк» для соответствующего тарифного плана |
| **2** | **Внесение наличных денежных средств в банкоматах Банка ГПБ (АО)[^3][^4] по картам платежных систем VISA International, MasterCard Worldwide, «Мир»** | |
| 2.1 | По картам физических лиц, за исключением карт, к которым применяется тариф «Твой кэшбэк» (тариф с 9 сентября 2020 г.), тариф «Карта жителя» | **0,8%** от суммы операции |
| 2.2 | По картам физических лиц, к которым применяется тариф «Твой кэшбэк» (тариф с 9 сентября 2020 г.), тариф «Карта жителя» | **0%** при общей сумме операций внесения до 50 000 рублей (включительно) в месяц (Лимит бесплатного внесения)<br><br>**0,8%** от суммы каждой операции, если общая сумма операций внесения превысила Лимит бесплатного внесения[^5] |
| **3** | **Внесение наличных денежных средств в банкоматах Банка ВТБ (ПАО)[^3][^4]:** | |
| 3.1 | по картам физических лиц платежных систем VISA International, MasterCard Worldwide | в соответствии с условиями, указанными в пп. 2.1 и 2.2 настоящих тарифов |
| 3.2 | по картам физических лиц платежной системы «Мир» | **0%** от суммы операции |
| **4** | **Внесение наличных денежных средств в банкоматах ПАО КБ «УБРиР», АО «АЛЬФА-БАНК», АО «СМП Банк», АО МОСОБЛБАНК** по картам физических лиц платежных систем VISA International, MasterCard Worldwide, «Мир» | **0%** от суммы операции |

## Примечания

[^1]: Настоящие Тарифы являются тарифами ПАО «Промсвязьбанк» и не включают комиссии других банков. Настоящие Тарифы дополняют Тарифы ПАО «Промсвязьбанк» по выпуску и обслуживанию банковских карт для физических лиц.

[^2]: К Банкам-партнерам по выдаче наличных денежных средств с использованием карт платежных систем VISA International, MasterCard Worldwide, «Мир» относятся АО «АЛЬФА-БАНК», АО «Россельхозбанк», ПАО КБ «УБРиР», АО «СМП Банк», АО МОСОБЛБАНК. Выдача наличных денежных средств через банкоматы указанных Банков-партнеров в рублях или эквиваленте в другой валюте осуществляется в пределах ежедневного суммарного лимита по картам в соответствии с действующими тарифами Банка по выпуску и обслуживанию банковских карт для физических лиц (в том числе в рамках Сборника Тарифов по выпуску и обслуживанию банковских карт для физических лиц, эмитируемых ПАО «Промсвязьбанк») и корпоративных банковских карт для юридических лиц и индивидуальных предпринимателей. Со стороны Банков-партнеров могут быть установлены дополнительные лимиты на выдачу наличных денежных средств.

[^3]: Внесение наличных денежных средств через банкоматы АО «АЛЬФА-БАНК», Банк ГПБ (АО), Банк ВТБ (ПАО), ПАО КБ «УБРиР», АО «СМП Банк», АО МОСОБЛБАНК осуществляется в рублях в пределах лимитов, установленных в соответствии с тарифами указанных банков.

[^4]: При внесении наличных денежных средств в банкоматах других Банков-партнеров ПАО «Промсвязьбанк» и сторонних банков с клиента может взиматься комиссия в соответствии с тарифами данных Банков-партнеров.

[^5]: В случае, если сумма внесения превышает Лимит бесплатного внесения, комиссия за внесение в размере 0,8% применяется к той части суммы, которая превышает Лимит бесплатного внесения.

## Краткая сводка тарифов

### Выдача наличных
- Во всех банках-партнерах: по тарифу ПСБ для соответствующего плана

### Внесение наличных

**Банк ГПБ (VISA/MasterCard/Мир):**
- Обычные карты: 0,8%
- «Твой кэшбэк» и «Карта жителя»: 0% до 50 000₽/месяц, затем 0,8%

**Банк ВТБ:**
- VISA/MasterCard: как в ГПБ
- Карты «Мир»: 0%

**УБРиР, Альфа-Банк, СМП Банк, МОСОБЛБАНК:**
- Все карты: 0%
