## <a id="типы-карт"></a>2. Типы банковских карт

### 2.1 По статусу владельца

#### Основная карта
**Определение:** Банковская карта, выпущенная на имя владельца счета (Клиента).

**Характеристики:**
- Привязана к личному счету Клиента
- Дает полный доступ к операциям
- Может иметь дополнительные карты
- Выпускается первой при открытии счета

**Пример:**
```
Иванов И.И. открывает счет → получает Основную карту
Счет: 40817810099910123456
Карта: 5536 9137 XXXX XXXX
```

#### Дополнительная карта
**Определение:** Карта, выпущенная дополнительно к Основной на имя Клиента или его Представителя.

**Характеристики:**
- Привязана к счету Основной карты
- Может иметь ограничения по операциям
- Выпускается по заявлению владельца Основной карты
- Лимиты общие с Основной картой

**Пример:**
```
Основная карта: Иванов И.И.
Дополнительная карта: Иванова М.П. (супруга)
Оба пользуются одним счетом: 40817810099910123456
```

**Важно:** Дополнительная цифровая карта выпускается ТОЛЬКО на имя Клиента (не на Представителя).

### 2.2 По форме выпуска

#### Обычная карта (с пластиком)
**Характеристики:**
- Физический пластиковый носитель
- Выдается в отделении или доставляется курьером
- Имеет магнитную полосу и/или чип
- Срок изготовления: 3-10 рабочих дней

#### Цифровая карта
**Определение:** Банковская карта без физического носителя, выпускаемая через систему PSB-Retail.

**Характеристики:**
- Мгновенный выпуск онлайн
- Реквизиты доступны сразу в приложении
- Можно заказать пластик позже отдельным заявлением
- Работает через Apple Pay, Google Pay, Samsung Pay

**Процесс выпуска:**
```
1. Клиент → Заявка через PSB-Mobile
2. Банк → Мгновенно создает Цифровую карту
3. Клиент → Видит номер карты в приложении
4. Клиент → Опционально заказывает пластик (Материальный носитель)
```

#### Дополнительная цифровая карта
**Особенности:**
- Выпускается только на имя Клиента
- Дополнительно к Основной карте
- Также можно заказать пластик отдельно

#### Виртуальная карта
**Определение:** Карта без физического носителя для специальных операций.

**Типы:**

**а) Дополнительная виртуальная карта**
- Только для операций через кассу Банка
- Только расходные операции
- Выпускается по заявлению в офисе

**б) Дополнительная виртуальная карта "Мир"**
- Платежная система "Мир"
- Максимум 2 карты к одному договору
- Без материального носителя

#### Материальный носитель
**Определение:** Пластиковая карта к ранее выпущенной Цифровой карте.

**Важно:**
- Реквизиты на пластике = реквизиты Цифровой карты
- Не является отдельной картой
- Заказывается отдельным заявлением

**Пример:**
```
Этап 1: Выпуск Цифровой карты
         5536 9137 1234 5678

Этап 2: Заказ пластика
         Тот же номер: 5536 9137 1234 5678
```

### 2.3 По информации на карте

#### Именная карта
**Характеристики:**
- На лицевой стороне указаны фамилия и имя
- Пример: IVAN IVANOV
- Срок изготовления: 5-10 дней

#### Неименная карта
**Характеристики:**
- Без указания ФИО держателя
- Обычно моментальная выдача
- Могут быть ограничения по операциям

### 2.4 Специальные формы

#### Стикер
**Определение:** Карта с отделяемой частью в форме наклейки для бесконтактных платежей.

**Конструкция:**
```
┌─────────────────────────┐
│ БОЛЬШАЯ ЧАСТЬ           │
│ 5536 9137 XXXX XXXX     │  ← Реквизиты карты
│ IVAN IVANOV             │
│ 12/27                   │
├─────────────────────────┤
│ [ЧИП] СТИКЕР            │  ← Отделяемая часть с NFC
└─────────────────────────┘
```

**Применение:**
- Большая часть: операции с вводом реквизитов
- Стикер: бесконтактные платежи (наклеить на телефон/чехол)

## <a id="участники"></a>3. Участники и роли

### 3.1 Основные участники

#### Клиент
**Определение:** Физическое лицо, заключившее Договор о выпуске карты.

**Права:**
- Владелец счета
- Открывает Основную карту
- Может выпускать Дополнительные карты
- Полный контроль над счетом

**Обязанности:**
- Соблюдать условия договора
- Оплачивать услуги по тарифам
- Обеспечивать безопасность карты

#### Держатель
**Определение:** Лицо, на имя которого выпущена карта (Клиент или Представитель).

**Примеры:**
```
Основная карта → Держатель = Клиент
Дополнительная карта на супругу → Держатель = Представитель (супруга)
Дополнительная цифровая карта → Держатель = Клиент (только!)
```

#### Представитель
**Определение:** Физическое лицо с правом операций по счету Клиента.

**Характеристики:**
- Клиент предоставил ему право пользоваться счетом
- На его имя выпущена Дополнительная карта
- НЕ является владельцем счета
- НЕ может выпускать другие Дополнительные карты

**Пример:**
```
Клиент: Иванов И.И. (владелец счета)
Представитель: Иванова М.П. (супруга, пользуется счетом)
```

**Важно:** Дополнительная цифровая карта НЕ выпускается на Представителя.

#### Представитель по доверенности
**Определение:** Лицо с нотариальной доверенностью на все операции по карте и счету.

**Полномочия (по доверенности):**
- Выпуск Банковских карт
- Получение карт в банке
- Выпуск Дополнительных карт на свое имя
- Выпуск Дополнительных карт на имя Представителей
- Все операции по счету

**Важно:** Может быть одновременно и Представителем (если выпущена Дополнительная карта на его имя).

**Требования к доверенности:**
- Нотариальное удостоверение
- Или приравненное к нотариальному (по законодательству РФ)
- Явное указание полномочий по карте/счету

### 3.2 Зарплатные проекты

#### Работник
**Определение:** Клиент, получающий зарплату на счет по Договору зарплатного проекта.

**Источники:**
- Организация-работодатель перечисляет зарплату
- Или сам Банк (для своих сотрудников)

#### Организация-работодатель
**Определение:** Юридическое лицо / ИП / госорган с Договором зарплатного проекта.

**Функции:**
- Перечисляет зарплату сотрудникам
- Предоставляет реестры платежей
- Банк выпускает карты работникам

### 3.3 Партнеры

#### Организация торговли (услуг)
**Определение:** Юридическое лицо или ИП, принимающий карты в оплату.

**Примеры:**
- Магазины
- Рестораны
- Интернет-магазины
- Сервисные центры

#### Организация-партнер
**Определение:** Юридическое лицо с договором о совместных программах с Банком.

**Примеры программ:**
- Кобрендинговые карты
- Бонусные программы
- Специальные тарифы

**Полное название:** АО «Национальная система платежных карт»

**Адрес:**
```
115184, Москва

```

**Функция:** Оператор платежной системы «Мир».

### 5.2 Дистанционные каналы

#### Система PSB-Retail
**Определение:** Программно-технический комплекс для дистанционного обслуживания.

**Характеристики:**
- Тип: «Клиент-банк»
- Оператор: ПАО «Банк ПСБ»
- Доступ: через интернет, мобильные приложения
- Функции: переводы, платежи, управление картами

**Является Электронным средством платежа (ЭСП).**

**Платформы:**
- iOS (iPhone, iPad)
- Android (смартфоны, планшеты)

**Возможности:**
- Доступ к Системе PSB-Retail
- Просмотр операций
- Переводы и платежи

- Управление картами

#### Личный кабинет
**Определение:** Область в Системе PSB-Retail после входа в систему.

**Доступ:**
1. Идентификация (ввод логина/телефона)
2. Аутентификация (ввод пароля/кода)

## <a id="операции"></a>6. Операции с картами

### 6.1 Основные термины операций

#### Авторизация
**Определение:** Разрешение Банка на проведение операции.

**Процесс:**
```
1. Держатель → Операция с картой
2. Терминал → Запрос в Банк
3. Банк → Проверка лимитов и безопасности
4. Банк → Разрешение (авторизация) или отказ
5. Терминал → Операция проводится
```

**Важно:** Авторизация порождает обязательство Банка по исполнению операции.

#### Поручение
**Определение:** Распоряжение Клиента на совершение операции по счету.

**Способы оформления:**
- Документ по операциям с картой (чек, слип)
- Через Систему PSB-Retail
- Через банкомат
- Через Контакт-центр (для некоторых операций)

**Содержание:**
- Реквизиты получателя
- Сумма операции
- Назначение платежа
- Подтверждение (подпись, ПИН-код, Средство подтверждения)

#### Платежный лимит
**Определение:** Сумма, доступная для операций.

**Состав:**
```
Платежный лимит = Остаток на счете + Доступный кредит (если есть)
```

**Пример:**
```
Остаток на счете: 10 000₽
Кредитный лимит: 50 000₽ (по Соглашению о кредитовании)
Платежный лимит: 60 000₽
```

#### Несанкционированная задолженность
**Определение:** Превышение расходов над Платежным лимитом.

**Причины:**
- Операции без авторизации (некоторые терминалы)
- Технические сбои
- Курсовые разницы
- Комиссии третьих сторон

**Обязательство:** Клиент должен погасить задолженность.

### 6.2 Документы по операциям

#### Документ по операциям с картой
**Формат:**
- Бумажный носитель (чек, слип)
- Электронная форма

**Функции:**
- Основание для расчетов
- Подтверждение операции
- Данные для выписки

**Примеры:**
- Чек из банкомата
- Слип из терминала магазина
- Электронный чек на email
- Квитанция онлайн-операции

#### Выписка по счету
**Определение:** Отчет об операциях за период.

**Содержание:**
- Дата и время операций
- Описание операций
- Суммы списаний и зачислений
- Операции с использованием ЭСП
- Остаток на начало и конец периода
- Доступный остаток

**Получение:**
- В Личном кабинете
- В банкомате
- В отделении Банка
- По email (при подключении сервиса)

#### Реестр платежей
**Определение:** Документ с информацией об операциях за период.

**Источник:** Компания - процессинговый центр платежной системы.

**Формат:**
- Электронный
- Бумажный (при необходимости)

**Назначение:** Основание для расчетов и отражения операций.

#### Электронный журнал
**Определение:** Документ об операциях в банкомате.

**Характеристики:**
- Формируется автоматически
- Только в электронной форме
- За определенный период
- Используется для расчетов и выверки

### 6.3 Технологии платежей

#### Технология бесконтактных платежей
**Определение:** Оплата путем поднесения карты к терминалу.

**Технологии:**
- NFC (Near Field Communication)
- RFID

**Процесс:**
```
1. Держатель → Подносит карту к терминалу
2. Терминал → Считывает данные бесконтактно
3. До определенной суммы → Без ввода ПИН-кода
4. Свыше лимита → Требуется ПИН-код
```

**Лимит без ПИН-кода:** Обычно до 1000-3000₽ (зависит от настроек).

**Типы носителей:**
- Карта с NFC-чипом
- Стикер с NFC-чипом
- Смартфон с Apple Pay / Google Pay / Samsung Pay
- Умные часы

#### 3D-Secure
**Определение:** Технология безопасности для интернет-платежей.

**Процесс:**
```
1. Клиент → Вводит реквизиты карты на сайте
2. Сайт → Перенаправляет на страницу 3D-Secure
3. Банк → Отправляет код подтверждения (SMS/Push)
4. Клиент → Вводит код
5. Банк → Подтверждает операцию
6. Сайт → Операция завершена
```

**Коды:**
- 3D-Secure (VISA)
- SecureCode (MasterCard)
- MirAccept (Мир)

**Безопасность:** Дополнительная аутентификация клиента.

## <a id="договоры"></a>7. Договоры и соглашения

### 7.1 Основной договор

#### Договор о выпуске и обслуживании карты
**Полное название:** Договор о выпуске и обслуживании банковской карты

**Тип:** Договор присоединения к Правилам по банковским картам.

**Заключение:**
```
Клиент → Заявление на выпуск карты
Банк → Принятие заявления
Момент заключения → Принятие Банком заявления
```

- Выполнение распоряжений Клиента
- Операции со счетом

**Подтверждение:** Банк направляет Подтверждение о заключении договора (SMS, email, в Личном кабинете).

### 7.2 Дополнительные договоры

#### Договор ДБО (Дистанционное банковское обслуживание)
**Полное название:** Договор дистанционного банковского обслуживания

**Регулирование:** Правила ДБО (дистанционного банковского обслуживания)

**Заключение:** Присоединение к Правилам ДБО

**Содержание:**
- Предоставление дистанционного обслуживания
- Использование Каналов доступа
- Использование Средств подтверждения
- Права и обязанности сторон

**Возможности:**
- Переводы и платежи через интернет/приложение
- Просмотр информации по счетам
- Управление картами
- Другие банковские операции

#### Договор ДКО (Комплексное обслуживание)
**Полное название:** Договор комплексного банковского обслуживания

**Регулирование:** Правила комплексного обслуживания

**Заключение:** Присоединение к Правилам комплексного обслуживания

**Содержание:**
- Предоставление двух и более банковских услуг
- Условия и порядок их предоставления
- Единые условия обслуживания

**Примеры Комплексных продуктов:**

#### Соглашение о кредитовании счета
**Регулирование:** Правила кредитования счета

**Заключение:** Присоединение к Правилам кредитования счета

**Содержание:**
- Предоставление потребительских кредитов с лимитом
- Условия пользования кредитом
- Проценты за кредит
- Порядок погашения

**Тип кредита:** Кредит с лимитом кредитования (овердрафт, кредитная карта).

**Пример:**
```
Клиент → Соглашение о кредитовании
Банк → Устанавливает лимит 100 000₽
Клиент → Расходует 120 000₽ (свои 20 000₽ + кредит 100 000₽)
Клиент → Гасит кредит + проценты по условиям Соглашения
```

#### Договор зарплатного проекта
**Стороны:**
- Банк
- Организация-работодатель

**Содержание:**
- Открытие счетов работникам
- Выпуск карт работникам
- Перечисление зарплаты на счета
- Условия обслуживания

**Для работников:**
- Специальные тарифы (обычно льготные)
- Автоматический выпуск карт
- Зачисление зарплаты

### 7.3 Заявления

#### Заявление на выпуск банковской карты
**Форма:** Установленная Банком (Анкета-заявление)

**Способы подачи:**
- Лично в офисе
- Через PSB-Retail (для Цифровых карт)
- Онлайн на сайте

**Содержание:**
- Персональные данные
- Тип карты
- Валюта счета
- Тарифный план
- Согласие на обработку ПД

**Результат:** Заключение Договора о выпуске карты.

**Назначение:** Заказ пластика к Цифровой карте или Дополнительной цифровой карте.

**Способы подачи:**
- Через PSB-Retail
- Лично в офисе

**Важно:** Реквизиты на пластике = реквизиты Цифровой карты (не новая карта!).

#### Заявление на выпуск Дополнительной виртуальной карты
**Назначение:** Выпуск виртуальной карты для операций через кассу.

**Способ подачи:** Только лично в офисе.

**Кто может подать:**
- Клиент
- Представитель Клиента по доверенности

## <a id="зарплата"></a>8. Зарплатные проекты и услуги

### 8.1 Корпоративный зарплатный проект

#### Для кого
**Работник** - клиент, получающий зарплату по Договору зарплатного проекта.

#### Как работает
```
Работодатель → Договор с Банком
Работодатель → Реестр работников
Банк → Выпуск карт работникам
Работодатель → Перечисление зарплаты
Банк → Зачисление на счета работников
```

#### Преимущества
- Льготные тарифы
- Бесплатное обслуживание (часто)
- Специальные условия
- Корпоративные бонусы

### 8.2 Индивидуальный зарплатный проект (ИЗП)

#### Услуга ИЗП
**Определение:** Предоставление услуг без корпоративного Договора зарплатного проекта.

**Для кого:** Клиенты, получающие зарплату на карту ПСБ, но не в рамках корпоративного проекта.

#### Условия предоставления

**Зачисления от работодателя:**
- От юридических лиц (ИНН из 10 цифр)
- От индивидуальных предпринимателей
- НЕ от физических лиц

**Учет зачислений:** На 3-й календарный день после поступления.

#### Льготный период
**Длительность:** 2 полных календарных месяца с момента выбора счета для ИЗП.

**Условия:** В течение Льготного периода услуги ИЗП предоставляются независимо от размера зачислений.

**Пример:**
```
15 марта → Клиент выбрал счет для ИЗП
15 марта - 30 апреля - 31 мая → Льготный период
С 1 июня → Расчет Среднемесячных зачислений
```

#### Расчетный период
**Определение:** С 26 числа месяца по 25 число следующего месяца.

**Пример:**
```
Расчетный период № 1: 26 января - 25 февраля
Расчетный период № 2: 26 февраля - 25 марта
И так далее...
```

#### Среднемесячные зачисления
**Расчет 26 числа каждого месяца:**

```
Среднемесячные зачисления = 
    Сумма (Зачисления от работодателя + Зачисления СБП)
    ──────────────────────────────────────────────────────
    Количество Расчетных периодов с такими зачислениями
```

**Условия:**
- Анализируются последние 6 Расчетных периодов
- Учитываются только периоды с зачислениями
- Минимум 3 периода из 6 должны иметь зачисления

**Пример расчета:**

```
Зачисления по месяцам:
Январь (26.12-25.01): 50 000₽ зарплата + 10 000₽ СБП = 60 000₽
Февраль (26.01-25.02): 50 000₽ зарплата = 50 000₽
Март (26.02-25.03): 0₽ (не было)
Апрель (26.03-25.04): 55 000₽ зарплата = 55 000₽
Май (26.04-25.05): 50 000₽ зарплата + 5 000₽ СБП = 55 000₽
Июнь (26.05-25.06): 50 000₽ зарплата = 50 000₽

Расчет 26 июня:
Среднемесячные = (60 000 + 50 000 + 55 000 + 55 000 + 50 000) / 5
Среднемесячные = 270 000 / 5 = 54 000₽

(март не учитывается, так как не было зачислений)
```

#### Зачисления СБП
**Определение:** Переводы из других банков на свой счет через СБП.

**Условия:**
- Клиент сам переводит себе с другого счета
- Через Сервис быстрых платежей
- Учитываются при расчете Среднемесячных зачислений

**Пример:**
```
Клиент получает зарплату в Сбербанке
Клиент переводит себе в ПСБ через СБП
→ Это зачисление учитывается для ИЗП
```

## <a id="безопасность"></a>9. Безопасность и аутентификация

### 9.1 Идентификаторы

#### Идентификатор
**Определение:** Информация, однозначно выделяющая Клиента.

**Типы:**
- Номер Клиента
- Логин
- Номер карты
- Номер счета
- Номер телефона

#### Номер Клиента
**Формат:** Комбинация цифр (натуральное число).

**Назначение:** Уникальный идентификатор в системе Банка.

**Пример:** 1234567890

#### Логин
**Формат:** Комбинация цифр, букв и слов.

**Назначение:** Дополнительный идентификатор по выбору Клиента.

**Пример:** ivan.ivanov или mylogin2024

#### Номер телефона
**Назначение:**
- Идентификатор для входа в Систему
- Получение SMS-сервисов
- Переводы по номеру телефона (СБП)

**Формат:** +7 999 123-45-67

### 9.2 Средства аутентификации

#### Аутентификация
**Определение:** Подтверждение принадлежности Идентификатора предъявителю.

**Цель:** Убедиться, что Клиент - это действительно Клиент.

#### ПИН-код
**Определение:** Персональный идентификационный номер карты.

**Характеристики:**
- Уникален для каждой карты
- 4-6 цифр
- Аналог собственноручной подписи
- Известен только Держателю

**Использование:**
- Операции в банкоматах
- Операции в терминалах
- Подтверждение бесконтактных платежей свыше лимита

**Безопасность:**
- Не сообщать никому (даже сотрудникам Банка!)
- Не записывать вместе с картой
- Менять при подозрении на компрометацию

#### Пароль
**Определение:** Последовательность символов для аутентификации.

**Использование:**
- Вход в Систему PSB-Retail
- Подтверждение операций
- Обслуживание по Каналам доступа

**Характеристики:**
- Многократное использование
- Известен только Клиенту
- Может меняться

#### Кодовое слово
**Определение:** Последовательность символов для аутентификации в Контакт-центре.

**Использование:**
- Звонок в Контакт-центр
- Идентификация по телефону

**Характеристики:**
- Уникальное для Клиента
- Многократное использование
- Устанавливается при выпуске карты
- Можно изменить

**Установка/замена:**
- В отделении Банка
- Через Систему PSB-Retail
- По телефону (после аутентификации другим способом)

#### Средство подтверждения
**Определение:** Электронное средство для подтверждения операций.

**Типы:**
- Одноразовый пароль (OTP) по SMS
- Одноразовый пароль через Push
- Электронная подпись
- Биометрия (в мобильном приложении)

**Использование:**
- Подтверждение платежей в интернет-банке
- Подтверждение входа в систему
- Подтверждение изменения настроек

**Пример:**
```
Клиент → Платеж в PSB-Mobile
Банк → Отправка кода 1234 по SMS
Клиент → Ввод кода 1234
Банк → Подтверждение операции
```

### 9.3 Процессы безопасности

#### Идентификация
**Определение:** Определение личности Клиента по Идентификатору.

**Процесс:**
```
Клиент → Предъявляет Идентификатор (логин, номер карты)
Банк → Находит Клиента в базе
```

#### Полная аутентификация
**Процесс:**
```
1. Идентификация (логин/номер)
2. Аутентификация (пароль/ПИН-код)
3. Дополнительное подтверждение (OTP код)
```

#### Компрометация конфиденциальной информации
**Определение:** Утрата уверенности в конфиденциальности данных.

**Признаки:**
- Карта утеряна или украдена
- ПИН-код стал известен третьим лицам
- Пароль скомпрометирован
- Подозрительные операции
- Фишинговая атака

**Действия при компрометации:**
```
1. Немедленно → Блокировка карты
   - Через PSB-Mobile
   - Через Контакт-центр: 8-495-787-33-33
   - В отделении Банка

2. Смена → Пароли, ПИН-коды

3. Перевыпуск → Новая карта

4. Мониторинг → Операции по счету
```

#### Стоп-лист
**Определение:** Платная услуга блокировки всех операций по карте.

**Характеристики:**
- Защита от ВСЕХ операций
- Включая операции без авторизации
- Оплачивается по Тарифам
- Более надежная, чем обычная блокировка

**Применение:**
- При утере карты
- При подозрении на мошенничество
- На время отъезда

## <a id="faq"></a>10. Часто задаваемые вопросы (FAQ)

### Вопросы о картах

**Q: В чем разница между Основной и Дополнительной картой?**

A: Основная карта выпускается на владельца счета (Клиента). Дополнительная карта выпускается дополнительно на имя Клиента или Представителя. Обе привязаны к одному счету и используют общий лимит.

---

**Q: Могу ли я выпустить Дополнительную цифровую карту на свою супругу?**

A: Нет. Дополнительная цифровая карта выпускается ТОЛЬКО на имя Клиента (владельца счета). Для супруги можно выпустить обычную Дополнительную карту (с пластиком).

---

**Q: Что такое Цифровая карта?**

A: Цифровая карта - это банковская карта без физического пластика. Выпускается мгновенно через приложение PSB-Mobile. Реквизиты сразу доступны для онлайн-платежей и добавления в Apple Pay/Google Pay. Пластик можно заказать позже отдельно.

---

**Q: Чем Материальный носитель отличается от новой карты?**

A: Материальный носитель - это пластик к уже существующей Цифровой карте с ТЕМИ ЖЕ реквизитами. Это не новая карта, а физическое воплощение цифровой карты.

---

**Q: Сколько Дополнительных виртуальных карт "Мир" можно выпустить?**

A: Не более 2 (двух) к одному Договору о выпуске карты.

---

### Вопросы о тарифах

**Q: Сколько стоит снять наличные в банкомате Альфа-Банка?**

A: По тарифу ПСБ для вашего тарифного плана (как в родных банкоматах ПСБ). Альфа-Банк - партнер ПСБ для выдачи наличных.

---

**Q: Я вношу 70 000₽ в месяц в банкомат ГПБ по карте "Твой кэшбэк". Какая комиссия?**

A: 
```
50 000₽ - бесплатно (0%)
20 000₽ - комиссия 0,8% = 160₽
Итого комиссия: 160₽
```

---

**Q: Внесение в банкомат ВТБ по карте "Мир" - бесплатно?**

A: Да, 0% комиссии для карт платежной системы "Мир" в банкоматах ВТБ.

**Q: Какие банкоматы для внесения наличных бесплатные для всех карт?**

A: УБРиР, Альфа-Банк, СМП Банк, МОСОБЛБАНК - во всех бесплатно (0%) для карт VISA, MasterCard и "Мир".

### Вопросы о системах

**Q: Что такое PSB-Retail?**

A: Это система интернет-банка ПСБ. Доступна через веб-сайт (psbank.ru) и мобильное приложение PSB-Mobile для iOS и Android.

---

**Q: Как подключить СМС-информирование?**

A: 
1. Через PSB-Mobile: Настройки → Уведомления → SMS-информирование
2. В отделении Банка: заявление на подключение
3. Через Контакт-центр: 8-495-787-33-33

Укажите карту и номер телефона для SMS.

---

**Q: Что лучше: SMS или Push-уведомления?**

A: Push-уведомления:
- Бесплатно
- Быстрее
- Больше информации
- Но требуют интернет

SMS:
- Работают без интернета
- Платная услуга (по тарифам)

**Q: Что такое СБП и как им пользоваться?**

A: Сервис быстрых платежей Банка России. Позволяет переводить деньги по номеру телефона между разными банками мгновенно. Доступен в PSB-Mobile: Переводы → По номеру телефона.

### Вопросы о зарплатных проектах

**Q: Что такое Услуга ИЗП?**

A: Индивидуальный зарплатный проект - это льготные условия для клиентов, получающих зарплату на карту ПСБ, но НЕ в рамках корпоративного договора.

---

**Q: Как считаются Среднемесячные зачисления?**

A: 26 числа каждого месяца Банк суммирует зачисления от работодателя и переводы через СБП за последние 6 Расчетных периодов и делит на количество периодов с зачислениями (минимум 3 из 6).

---

**Q: Что такое Льготный период ИЗП?**

A: 2 полных календарных месяца с момента выбора счета для ИЗП. В этот период услуги ИЗП предоставляются независимо от суммы зачислений.

---

**Q: Учитываются ли переводы от родственников для ИЗП?**

A: Нет. Для ИЗП учитываются только:
- Зачисления от юридических лиц (ИНН 10 цифр) и ИП
- Переводы СЕБЕ из других банков через СБП

Переводы от физических лиц НЕ учитываются.

### Вопросы о безопасности

**Q: Карта утеряна. Что делать?**

A:
```
1. НЕМЕДЛЕННО заблокируйте карту:
   - PSB-Mobile: Карты → Выбрать карту → Заблокировать
   - Телефон: 8-495-787-33-33
   - Отделение банка

2. Закажите перевыпуск карты:
   - В PSB-Mobile
   - В отделении
   - По телефону

3. Проверьте операции:
   - Выписка в PSB-Mobile
   - Сообщите о подозрительных операциях
```

---

**Q: ПИН-код забыл. Как восстановить?**

A: ПИН-код невозможно восстановить (его не знает даже Банк). Нужно перевыпустить карту с новым ПИН-кодом:
- Заявление в отделении
- Или через PSB-Mobile (для некоторых карт)

---

**Q: Кодовое слово - что это и зачем?**

A: Кодовое слово используется для идентификации при звонке в Контакт-центр. Это дополнительная защита: сотрудник банка спросит Кодовое слово перед предоставлением информации или выполнением операций по телефону.

---

**Q: Банк попросил ПИН-код по телефону. Это мошенники?**

A: ДА! Банк НИКОГДА не спрашивает ПИН-код, пароли, коды из SMS. Это 100% мошенники. Немедленно прекратите разговор и заблокируйте карту через официальные каналы.

---

### Вопросы о договорах

**Q: Как заключается Договор о выпуске карты?**

A: Путем присоединения к Правилам по банковским картам. Подаете Заявление на выпуск карты → Банк принимает → Договор заключен. Подтверждение придет по SMS/email/в Личный кабинет.

---

**Q: Нужно ли подписывать бумажный договор?**

A: Нет. Договор заключается путем присоединения (Заявление = акцепт оферты). Бумажного договора не требуется.

---

**Q: Что такое Договор ДБО?**

A: Договор дистанционного банковского обслуживания. Заключается присоединением к Правилам ДБО. Дает доступ к PSB-Retail (интернет-банк и приложение).

---

**Q: Могу ли я оформить Соглашение о кредитовании счета?**

A: Да, если Банк одобрит. Соглашение дает кредитный лимит к вашей карте (овердрафт). Условия: процентная ставка, порядок погашения - см. Правила кредитования счета.

---

### Вопросы об операциях

**Q: Что такое Авторизация?**

A: Разрешение Банка на операцию. Когда вы расплачиваетесь картой, терминал отправляет запрос в Банк, Банк проверяет лимиты и безопасность, затем дает разрешение (авторизацию).

---

**Q: Операция прошла авторизацию, но деньги не списались. Почему?**

A: Авторизация - это только резервирование суммы. Фактическое списание происходит позже (обычно 1-3 дня), когда Банк получит окончательные документы от продавца.

---

**Q: Что такое Несанкционированная задолженность?**

A: Превышение расходов над Платежным лимитом. Может возникнуть из-за операций без авторизации, курсовых разниц или комиссий. Клиент обязан погасить задолженность.

---

**Q: Где посмотреть Выписку по счету?**

A:
- PSB-Mobile: Счета → Выбрать счет → История операций
- Личный кабинет на сайте
- В банкомате: Другие операции → Выписка
- В отделении банка

---

### Вопросы о технологиях

**Q: Как работает бесконтактная оплата?**

A: Подносите карту/телефон к терминалу. До определенной суммы (обычно 1000-3000₽) - без ПИН-кода. Свыше - нужно ввести ПИН-код. Работает через NFC-чип в карте или смартфоне.

---

**Q: Что такое 3D-Secure?**

A: Технология безопасности для интернет-платежей. При оплате в интернете Банк отправляет вам код подтверждения по SMS или Push, который нужно ввести для завершения операции.

---

**Q: Как добавить карту в Apple Pay / Google Pay?**

A:
1. Откройте Wallet (Apple) или Google Pay
2. Нажмите "Добавить карту"
3. Сфотографируйте карту или введите реквизиты
4. Подтвердите код из SMS
5. Готово!
