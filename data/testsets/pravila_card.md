## <a id="термины"></a>Термины и определения

### Основные понятия

**Банк** — ПАО «Банк ПСБ»  
Адрес: 150003, г. Ярославль, ул. Республиканская, 16  
Лицензия: № 3251  
Телефон: 8-495-787-33-33  
Сайт: www.psbank.ru

**Банковская карта** — эмитируемая Банком расчетная карта для безналичных расчетов по Счету. Является Электронным средством платежа (ЭСП).

**Держатель** — Клиент или Представитель, на имя которого выпущена Банковская карта.

**Клиент** — физическое лицо, заключившее Договор о выпуске карты.

**Счет** — банковский счет для расчетов с использованием Банковской карты.

### Типы карт

**Основная карта** — карта, выпущенная на имя Клиента (владельца Счета).

**Дополнительная карта** — карта, выпущенная дополнительно к Основной на имя Клиента или Представителя.

**Цифровая карта** — карта без физического носителя, выпускаемая через Систему PSB-Retail.

**Дополнительная цифровая карта** — цифровая карта, выпущенная дополнительно к Основной только на имя Клиента.

**Дополнительная виртуальная карта** — карта без физического носителя для расходных операций через кассу Банка.

**Дополнительная виртуальная карта "Мир"** — не более 2 карт без носителя в системе "Мир".

**Именная карта** — карта с указанием фамилии и имени Держателя.

**Неименная карта** — карта без указания ФИО Держателя.

**Стикер** — карта с отделяемой частью-наклейкой для бесконтактных платежей.

**Материальный носитель** — пластиковый носитель к ранее выпущенной Цифровой карте.

### Технические термины

**Авторизация** — разрешение Банка на проведение операции с картой.

**Аутентификация** — подтверждение принадлежности Идентификатора предъявителю.

**ПИН-код** — уникальный цифровой код карты, аналог подписи Держателя.

**Идентификатор** — Номер Клиента, Логин, номер карты или Счета.

**Идентификация** — определение личности Клиента по Идентификатору.

**Кодовое слово** — последовательность символов для Аутентификации через Контакт-центр.

**Логин** — комбинация символов для идентификации в системе.

**Номер Клиента** — комбинация цифр в качестве Идентификатора.

**Номер телефона** — номер мобильного телефона как идентификатор для входа в Систему и получения SMS-сервисов.

**Пароль** — последовательность символов для Аутентификации по Каналам доступа.

**Средство подтверждения** — электронное средство для подтверждения подлинности Поручения.

### Системы и сервисы

**Система PSB-Retail (Система)** — программно-технический комплекс для дистанционного обслуживания.

**Мобильное приложение PSB-Mobile** — приложение для iOS/Android для доступа к Системе.

**Личный кабинет** — область удаленного обслуживания в Системе PSB-Retail.

**Банкомат** — устройство для выдачи/приема наличных и совершения операций.

**ПВН (Пункт выдачи наличных)** — специально оборудованное место для операций с наличными.

**Канал доступа** — канал передачи Поручений (Контакт-центр, интернет, банкомат и др.).

**Контакт-центр** — подразделение для обслуживания Клиентов.

**СМС-информирование** — услуга информирования об операциях по SMS.

**Технология Push** — передача информации через интернет на мобильное приложение.

**СБП (Сервис быстрых платежей)** — сервис платежной системы Банка России для переводов по номеру телефона.

**3D-Secure** — технология безопасности для интернет-платежей.

**Технология бесконтактных платежей** — оплата путем поднесения карты к устройству.

### Платежные системы

**Платежная система** — совокупность организаций для перевода денежных средств.

**НСПК** — АО «Национальная система платежных карт» (115184, Москва, Большая Татарская, 11).

**Валюта клиринга** — валюта приема распоряжений Платежной системой.

### Операции и документы

**Поручение** — распоряжение Клиента на совершение операции по Счету.

**Документ по операциям** — документ, являющийся основанием для расчетов с использованием карты.

**Выписка по Счету** — отчет об операциях за период и остатке средств.

**Реестр платежей** — документ с информацией об операциях за период.

**Электронный журнал** — документ об операциях в банкомате.

**Стоп-лист** — оплачиваемая блокировка всех операций по карте.

### Договоры и правила

**Договор о выпуске карты** — договор присоединения к Правилам по банковским картам.

**Договор ДБО** — договор о дистанционном банковском обслуживании.

**Договор ДКО** — договор комплексного банковского обслуживания.

**Соглашение о кредитовании счета** — соглашение о предоставлении кредитов с лимитом.

**Договор зарплатного проекта** — договор с Организацией-работодателем.

**Правила по банковским картам** — настоящий документ.

**Правила ДБО** — правила дистанционного обслуживания через PSB-Retail.

**Правила комплексного обслуживания** — правила предоставления комплексных продуктов.

**Правила кредитования счета** — правила потребительского кредитования.

**Руководство пользователя** — документ о порядке использования карты.

**Тарифы** — система ставок комиссий и условий их взимания.

### Финансовые термины

**Платежный лимит** — сумма, доступная для операций, включая возможный кредит.

**Задолженность** — долг Клиента перед Банком.

**Несанкционированная задолженность** — превышение расходов над Платежным лимитом.

### Зарплатные проекты

**Работник** — Клиент, получающий зарплату по Договору зарплатного проекта.

**Организация-работодатель** — юридическое лицо с Договором зарплатного проекта.

**Зачисления от работодателя** — безналичные зачисления с формата ИНН (10 знаков) или от ИП.

**Услуга ИЗП (Индивидуальный зарплатный проект)** — услуга для зачисления зарплаты вне рамок корпоративного проекта.

**Льготный период** — 2 полных календарных месяца с момента выбора Счета для ИЗП.

**Расчетный период** — с 26 числа месяца по 25 число следующего месяца.

**Среднемесячные зачисления** — расчет зачислений от работодателя и СБП за 6 расчетных периодов (минимум 3 с зачислениями).

### Дополнительные понятия

**Организация торговли (услуг)** — юридическое/физическое лицо, принимающее карты в оплату.

**Организация-партнер** — юридическое лицо с договором о совместных программах.

**Комплексный банковский продукт** — продукт с двумя и более банковскими услугами.

**Представитель** — физлицо с правом операций по Счету Клиента.

**Представитель по доверенности** — физлицо с нотариальной доверенностью на операции.

**ДБО (Дистанционное банковское обслуживание)** — предоставление услуг через Каналы доступа.

**Дистанционное информационное обслуживание** — предоставление информации по счетам и картам.

**Информирование об операциях с ЭСП** — уведомление об операциях согласно законодательству.

**Компрометация информации** — утрата уверенности в конфиденциальности данных.

**Персонализация** — нанесение информации на карту.

**Подтверждение** — уведомление о заключении Договора о выпуске карты.

**ЭСП (Электронное средство платежа)** — средство для составления и передачи распоряжений.

**Персональные данные (ПД)** — информация о Клиенте.

**Обработка ПД** — действия с персональными данными.

**Предпринимательская деятельность** — деятельность для систематического получения прибыли.

**Стороны** — Банк и Клиент при совместном упоминании.

### Заявления

**Заявление на выпуск банковской карты** — обращение для заключения Договора о выпуске карты.

**Заявление на выпуск Дополнительной виртуальной карты** — обращение для выпуска виртуальной карты.

**Заявление на получение Материального носителя** — обращение для получения пластика к Цифровой карте.

## <a id="общие-положения"></a>1. Общие положения и порядок заключения Договора

### 1.1 Область применения

Правила по банковским картам устанавливают:
- Порядок открытия и ведения Счета
- Порядок выпуска и обслуживания Банковских карт
- Отношения по Договорам, заключенным после 01.07.2014

Правила регулируют отношения по договорам, заключенным до 01.07.2014 в соответствии с:

**1.1.1** Правилами выпуска и обслуживания международных банковских карт ОАО «Промсвязьбанк» для физических лиц в рамках комплексного банковского обслуживания (утв. 18.03.2013)

**1.1.2** Правилами выпуска и обслуживания международных банковских карт ОАО «Промсвязьбанк» для физических лиц (утв. 01.11.2011)

**1.1.3** Правилами предоставления и обслуживания международных банковских карт ОАО «Промсвязьбанк» для физических лиц (утв. 09.06.2008)

**1.1.4** Правилами предоставления и использования банковских карт ОАО «Промсвязьбанк» (утв. 14.11.2005)

**1.1.5** Правилами предоставления и использования международных банковских карт VISA для физических лиц (с льготным периодом кредитования) ОАО «Промсвязьбанк» (утв. 22.06.2007)

### Преемственность с документами других банков

Настоящие Правила являются действующей редакцией документов следующих банков:

**ПАО АКБ «Связь-Банк»**  
Регулируют отношения по договорам, заключенным по 30.04.2020 включительно

**АО «РОСКОСМОСБАНК»**  
Регулируют отношения по договорам, заключенным по 30.04.2021 включительно

**АО «МИнБанк»**  
Регулируют отношения по договорам, заключенным по 30.04.2023 включительно (в рамках Условий комплексного банковского обслуживания)

**ООО «ЦРБ ДНР»**  
Регулируют отношения, возникшие до 07.07.2023 включительно (Приложение 2 к Договору банковского обслуживания)

**Госбанк ЛНР**  
Регулируют отношения, возникшие до 21.07.2023 включительно

**АО «СМП Банк»**  
Регулируют отношения по договорам, заключенным по 31.12.2023 включительно (Приложение № 9 к Правилам комплексного обслуживания)

### 1.2 Типовой характер

Правила по банковским картам являются типовыми для всех Клиентов, включая Работников, и определяют положения договора присоединения между Банком и физическими лицами.
